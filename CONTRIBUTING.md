# Como contribuir

1. Abra uma issue descrevendo a mudança antes de PRs grandes.
2. Rode `PYTHONPATH=. python3 -m pytest -q simsuite/tests` antes de enviar.
3. **DCO:** assine cada commit com `git commit -s` (Developer Certificate of Origin, https://developercertificate.org).
4. Nunca inclua chaves, dados brutos de campo com posição GNSS ou dados pessoais.
5. Perfis regionais só entram com fonte, data da conferência e estado (`verificado` ou `nao_verificado`).

Conduta: respeito e foco técnico. Idiomas: código e API em inglês; documentos em português e inglês.
