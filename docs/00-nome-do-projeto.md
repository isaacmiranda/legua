# 00 — Nome do projeto: Légua

**Data:** 15/11/2026. **Decisão:** o projeto se chama **Légua**.

## Por quê
- Evitar a colisão com nomes quase iguais na literatura, como o **AdapLoRa** (ICNP 2020), que confundem buscas e revisores (doc 05, "Nome e patentes").
- Evitar "LoRa" dentro da marca: é marca da Semtech (doc 03 §6; doc 05).
- Raiz cultural: a légua é a medida de distância do sertão cearense; distância é o que o LoRa entrega.

## Nomes que não se confundem com o projeto

| Onde aparece | Observação |
|---|---|
| "AdapLoRa" (com um só "t") | É o esquema do ICNP 2020, outro trabalho |
| `adaptsim`, pacotes de código antigos | Nome histórico da simulação; hoje é `simsuite` |
