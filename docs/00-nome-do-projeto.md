# 00 — Nome do projeto: Légua

**Data:** 15/11/2026. **Decisão:** o projeto passa a se chamar **Légua** (antes "AdaptLoRa").

## Por quê
- Evitar a colisão quase exata com o **AdapLoRa** (ICNP 2020), que confunde buscas e revisores (doc 05, "Nome e patentes").
- Evitar "LoRa" dentro da marca: é marca da Semtech (doc 03 §6; doc 05).
- Raiz cultural: a légua é a medida de distância do sertão cearense; distância é o que o LoRa entrega.

## Como ler os documentos anteriores
Os docs 01 a 05 ainda usam "AdaptLoRa" no texto. Leia **AdaptLoRa → Légua**, com duas exceções:

| Onde aparece | Mantém |
|---|---|
| "AdapLoRa" (com um só "t") | É o esquema do ICNP 2020, outro trabalho |
| `adaptsim`, pacotes de código antigos | Nome histórico da simulação; hoje é `simsuite` |
