# Política de segurança

Se você encontrou uma falha de segurança (por exemplo, no acordo de modo, na autenticação ou no contador
anti-replay), **não abra uma issue pública**. Use o recurso "Report a vulnerability" na aba Security
do repositório, ou escreva para o endereço de contato que o mantenedor listar no perfil do projeto.

Prazo-alvo de resposta inicial: 7 dias. Divulgação coordenada após a correção.
