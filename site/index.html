Como ler. Todos os números saem de modelos com parâmetros estimados (canal, corrente do PA, deriva, interferência). Servem para comparar e dimensionar, não para prever o campo. O perfil regulatório BR-2026 vem de fonte secundária e está nao_verificado; nada aqui afirma conformidade ou homologação. Ainda não há medições em hardware: os experimentos com as placas Heltec serão feitos em repositório próprio e, quando existirem, calibram estes modelos.

Gerado por tools/build_site.py a partir de simsuite/results/. Para atualizar: python3 -m simsuite.run_suite --escala quick && python3 tools/build_site.py. Nos gráficos, passe o mouse ou use as setas para ler os valores; o botão “Tabela” mostra os mesmos dados em texto.
